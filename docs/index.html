Android · Video creation & YouTube publishing

Shorts Studio

Shorts Studio는 짧은 동영상 소재를 탐색하고, 후보를 검증하고, 제목과 자막을 편집하여 완성된 MP4를 사용자가 승인한 YouTube 채널로 전송할 수 있도록 돕는 Android 앱입니다.

주요 기능

  • 짧은 동영상 후보 검색과 원본·길이·화면 비율 등 품질 확인
  • 선택한 영상에 맞는 제목·자막 구성과 MP4 생성
  • Google 계정의 YouTube 권한을 통해 업로드 대상 채널 확인
  • 허가된 영상의 비공개·공개·예약 업로드 및 업로드 결과 확인

Google 계정 권한을 사용하는 이유

Shorts Studio는 사용자의 YouTube 채널을 정확히 확인하고 사용자가 선택한 영상을 업로드하기 위해 YouTube 채널 조회 및 동영상 업로드 권한을 요청합니다. Google 로그인은 Android 기기의 외부 Chrome 브라우저를 통해 수행됩니다. 계정 비밀번호를 앱에 직접 입력하도록 요구하지 않습니다.

콘텐츠 이용 권한

업로드하려는 영상의 저작권과 재게시·편집 권한은 사용자가 확인해야 합니다. 검색 결과에 표시된 영상이라고 해서 자동으로 재이용 권한이 생기는 것은 아닙니다.

운영 및 문의

Shorts Studio는 개발·테스트 중인 소프트웨어입니다. 기능 제공 범위와 오류는 버전에 따라 달라질 수 있습니다. 프로젝트에 대한 문의는 GitHub 이슈를 이용할 수 있습니다.
