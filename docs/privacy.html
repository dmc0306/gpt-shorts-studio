Shorts Studio 개인정보처리방침

마지막 수정: 2026년 11월 16일

Shorts Studio는 짧은 영상의 검색, 편집, 저장 및 YouTube 업로드를 돕는 앱입니다. 이 문서는 Google 계정 연동 및 영상 제작 기능에서 어떤 정보를 사용할 수 있는지 설명합니다.

1. 접근하는 정보와 목적

  • Google/YouTube 연결: 승인받은 OAuth 인증 정보, YouTube 채널 이름과 ID, YouTube API가 반환한 업로드 결과를 처리해 사용자가 선택한 채널을 확인하고 동영상을 업로드합니다.
  • 영상 작업: 사용자가 선택하거나 앱에서 생성한 영상·이미지·제목·자막·프로젝트 설정 및 처리 기록을 편집, 재개, 중복 방지에 사용할 수 있습니다.
  • 진단: 실패 원인 및 작업 상태 등 오류 처리를 위한 진단 정보가 앱 내에서 사용될 수 있습니다. OAuth 액세스 토큰이나 인증 코드를 화면의 일반 오류 안내에 출력하지 않도록 설계되어 있습니다.

2. Google 권한

youtube.readonly는 연결된 YouTube 채널을 조회하는 데 사용하고, youtube.upload는 사용자가 선택한 영상을 YouTube에 게시하는 데 사용합니다. Shorts Studio는 Google 계정 비밀번호를 직접 수집하지 않으며, Google 인증 화면은 외부 Chrome에서 표시됩니다.

3. 저장과 전송

Android 앱은 Google OAuth 인증 상태를 기기 측 암호화 저장소를 사용하여 보관하도록 구현되어 있습니다. 프로젝트 자료와 업로드 이력은 앱의 저장소에 남을 수 있습니다. 사용자가 별도 서버 자동화를 설정하면 해당 서버에서도 운영에 필요한 OAuth 인증 정보와 작업 기록을 관리할 수 있습니다.

사용자가 YouTube 업로드를 실행하면 영상과 업로드 메타데이터가 Google/YouTube로 전송됩니다. 영상 후보 검색이나 AI 편집 기능을 이용할 때에는 해당 기능의 설정에 따라 영상 프레임, 입력 텍스트 또는 검색어가 Google Gemini, 검색 API 등 외부 처리 서비스로 전송될 수 있습니다. 각 서비스는 자체 약관과 개인정보처리방침을 적용할 수 있습니다.

4. 제어와 삭제

사용자는 앱의 YouTube 연결 해제 기능을 통해 계정 연결을 해제할 수 있으며, Google 계정의 제3자 앱 연결 관리에서도 권한을 검토하거나 철회할 수 있습니다. 로컬 앱 파일은 기기의 앱 데이터 제거 또는 앱 제거를 통해 삭제할 수 있습니다. 별도로 구성한 서버의 인증·작업 기록은 해당 서버의 운영 환경에서 별도로 삭제해야 합니다.

5. 제3자 제공 및 보호

사용자 요청에 따라 YouTube에 게시하거나 영상·검색 기능을 제공하는 과정에서 필요한 정보가 관련 API 공급자에게 전송될 수 있습니다. 데이터 접근은 기능 수행에 필요한 범위로 제한해야 하며, OAuth 자격 증명을 공개 저장소나 일반 로그에 게시해서는 안 됩니다.

6. 문의 및 변경

서비스 및 데이터 처리 문의는 프로젝트 이슈 페이지로 접수할 수 있습니다. 처리 방식이 바뀌면 이 문서를 업데이트해야 합니다.
